La philosophie de Nova

Nova n'a pas pour objectif d'être Python avec une nouvelle syntaxe. Nova possède sa propre façon de penser la programmation.

🟧 Simple by default.

Si une opération peut être écrite simplement sans perdre ses possibilités, Nova privilégie la simplicité.

Le but n'est pas de rendre le langage moins puissant, mais d'éviter la complexité inutile.

Une syntaxe qui se comprend

say: "Bonjour"

Une instruction simple doit rester simple.

Une syntaxe structurée

window: size: 800, 600 title: "Mon programme"

Les propriétés restent dans leur contexte. Ainsi, des mots comme title peuvent être utilisés pour différents objets sans créer d'ambiguïté.

Syntaxe de base

Afficher du texte

say: "Bonjour !"

Créer une variable

set name = "Mario" say: name

Condition

if: name == "Mario" say: "Hello Mario"

Répéter

repeat: 5 say: "Bonjour"

Bibliothèques

Les bibliothèques peuvent être chargées avec use:.

use: math say(math): 8 * 97 say(math): 9 - 47 say(math): 1637 + (283 - 594) * (42 + 4)

Le principe est de rendre l'utilisation d'une bibliothèque directement compréhensible.

Documentation Nova 0.4

say

Affiche une valeur ou un texte.

say: "Hello world" say: name

set

Crée une variable.

set score = 100 set name = "Mario"

if

Exécute un bloc lorsque la condition est vraie.

if: score >= 100 say: "Gagné !"

repeat

Répète un bloc plusieurs fois.

repeat: 3 say: "Nova"

use

Charge une bibliothèque.

use: math

window

Définit une fenêtre et ses propriétés.

window: size: 800, 600 title: "Nova App"

Open source

Nova est un projet open source destiné à rendre la programmation plus simple, plus lisible et plus accessible aux débutants.

Nova ne cherche pas à remplacer Python. Elle cherche à proposer une autre façon de programmer.
