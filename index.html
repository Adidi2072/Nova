Nova est conçu pour rendre la programmation plus simple à comprendre.

Une syntaxe volontairement simple et facile à retenir.

🚀

Évolutif

Nova commence petit, mais peut évoluer avec de nouvelles fonctionnalités.

Votre premier programme

Quelques caractères suffisent. 

# Mon premier programme Nova

Documentation

Les principales commandes disponibles dans Nova 0.1.

say

Affiche un texte ou une variable.

set

Crée une variable.

window

Crée une fenêtre avec une largeur et une hauteur.

windowname

Définit le nom de la fenêtre.

inwindow

Permet d'exécuter une commande à l'intérieur d'une fenêtre.

comment

Ajoute un commentaire dans le programme.

À propos de Nova

Nova est un langage de programmation créé pour être simple, lisible et accessible.


Son objectif n'est pas de remplacer Python ou de devenir aussi grand que lui. Nova cherche simplement à proposer une autre manière de découvrir la programmation.
